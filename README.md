# BarkCam — browser flasher

Public browser flasher for Bark Cam, hosted at https://snail3d.github.io/barkcam/

The flasher is unlocked with a Polar license key (BarkCam — Flasher Access).
Buy one at https://snail3d.com/lab/#barkcam

`docs/` is the GitHub Pages site: the flasher page, the bundled esptool,
and the merged firmware image. Safari/Firefox have no WebSerial — use
Chrome or Edge, or download the bin behind the same license gate.

Firmware source lives in the private `snail3d-lab/barkcam-source` repo.
